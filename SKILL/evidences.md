Crie uma tabela chamada sciclo.evidencies para que o usuário coloque o link das evidências, com uma descrição, o título da evidência pegue direto da URL.
Para evidência está vinculado a um item do questionário certificacao_questoes

Para questão do formulário inclua uma opção para inserir uma evidência.
Para inserir as evidências o usuário pode reutilizar evidências já inseridas

Ao "##### Inserir evidência" mostre o resultado se a evidência foi inserida com sucesso apresetando o ítulo, se deu erro mostre o erro.
